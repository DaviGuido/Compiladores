A entrega em que o compilador deixa de analisar e passa a **produzir**. No fim

## O que fazer

São três peças, e é por isso que esta entrega vale mais que as outras:

1. `mplc/intermediario.py` — o código de três endereços.
2. `mplc/gerador.py` — a tradução para o `.mplb`.
3. `mplc/vm.py` — a máquina que executa o `.mplb`.

```bash
./compilar --ir exemplos/tudo.mpl
```

```bash
./compilar exemplos/tudo.mpl && ./executar exemplos/tudo.mplb
```

```bash
make verificar E=4
```

## O que precisa estar funcionando

- **Três endereços de verdade**: no máximo um operador por linha do `--ir`.
  Essa é a única propriedade medida, e é a definição da representação.
- Os dez programas do corpus rodando com a saída **exata**. Inclui o
  formato de cada tipo: `real` sempre com seis casas decimais, `logico` como
  `verdadeiro`/`falso`.
- **Recursão**, direta e mútua. Sem registro de ativação não funciona.
- Divisão por zero e estouro de pilha viram erro de execução, com código de
  saída 2.
- As Entregas 1, 2 e 3 continuam verdes.

## As três armadilhas desta entrega

**A divisão inteira.** `7 / 2` é `3`, e `real x = 7 / 2;` é `3.000000` — a
divisão acontece **antes** da conversão. Quem promove cedo demais escreve
`3.500000` e passa em todo o resto do corpus. Tem um programa no corpus só
para isso.

**O sinal do resto.** `-7 % 3` é `-1`, não `2`. O resto tem o sinal do
dividendo. Se vocês usarem o `%` do Python direto, dá `2` e o teste fica
vermelho — o `%` do Python segue o sinal do divisor.

**O registro de ativação.** A recursão só funciona se cada chamada tiver o
seu próprio espaço de locais. Se os locais forem globais da VM, `fatorial(5)`
devolve lixo — e, pior, `fatorial(1)` funciona perfeitamente. É a matéria da
aula 11 virando código.

## O que entregar

1. As três peças preenchidas.
2. `evidencias/verificacao-4.txt`.
3. **Um programa MPL escrito por vocês**, em `exemplos/`, que faça algo que

## Como é corrigido

| | |
|---|---|
| Verificação verde numa máquina limpa (as quatro entregas) | 0,9 |
| Três endereços de verdade no `--ir` | 0,3 |
| Conjunto de instruções documentado no README | 0,3 |
| Programa próprio, funcionando | 0,3 |

Descontos: `.mplb` binário ou ilegível (0,0 na terceira linha — o contrato
pede texto legível, e na apresentação a gente vai abrir um e ler junto).
