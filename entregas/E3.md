# Entrega 3 — Tabela de símbolos e verificação de tipos

**Vale 1,2** · **Turma A: 28/10** · **Turma B: 26/10** · em grupo

Descobrir o que cada nome significa, em que escopo ele vive, e recusar o que
não faz sentido.

---

## O que fazer

Preencher `mplc/semantica.py`: a tabela de símbolos com escopos aninhados, e
a verificação de tipos da [seção 3 da especificação](../LINGUAGEM.md).

```bash
./compilar --tabela exemplos/tudo.mpl
```

```bash
make verificar E=3
```

## O que precisa estar funcionando

- Escopos aninhados **com sombreamento**: uma variável declarada dentro de um
  bloco esconde a de fora enquanto durar, e a de fora volta ao fechar.
- O corpo de uma função abre **dois** escopos: o dos parâmetros e o do bloco.
  Cada `se` e cada `enquanto` abre mais um, mesmo vazio.
- Duas passadas: a primeira coleta as assinaturas de todas as funções, para
  que uma função possa ser chamada antes de aparecer no arquivo.
- A conversão `inteiro` → `real`, e **só** ela.
- Função com retorno declarado precisa garantir o retorno em **todos** os
  caminhos.
- Os catorze erros semânticos do corpus, cada um na linha certa.

## A armadilha desta entrega

O caminho sem `retorne`. Isto aqui é erro:

```mpl
funcao inteiro sinal(inteiro n) {
  se (n > 0) {
    retorne 1;
  }
}
```

Um `se` sem `senao` **nunca** garante retorno, ainda que a condição pareça
sempre verdadeira para vocês. O compilador não avalia condições — ele olha a
estrutura. Um `se/senao` em que os dois lados retornam, esse garante.
